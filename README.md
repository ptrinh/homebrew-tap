# ptrinh/homebrew-tap

Homebrew tap for my apps.

## Proxy Switchboard

```sh
brew install --cask ptrinh/tap/proxy-switchboard
```

A lightweight macOS menu-bar app that routes traffic per destination through
SSH/SOCKS/WireGuard/Tor/HTTP proxies. See
https://github.com/ptrinh/proxy-switchboard-dist

## touchenv

```sh
brew install --cask ptrinh/tap/touchenv
```

Keep API keys and private keys in the macOS Keychain, every read behind Touch ID, so AI agents can ask but
only your finger says yes. See https://github.com/ptrinh/touch-env
