## Proxy Switchboard

```sh
brew install --cask ptrinh/tap/proxy-switchboard
```

A lightweight macOS menu-bar app that routes traffic per destination through
SSH/SOCKS/WireGuard/Tor/HTTP proxies. See
https://github.com/ptrinh/proxy-switchboard-dist
